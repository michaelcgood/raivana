# Security policy

Please report security vulnerabilities privately to **michael@vectoraccessgroup.com**, with
"Raivana security" in the subject line. Do not open public issues for vulnerabilities.

Include the affected version, steps to reproduce, and the impact. We aim to acknowledge reports within
3 business days.

Raivana generates access control policy. Always review generated policy, and test it with
`raivana test` / `raivana verify`, before deploying it to a production enforcement point.
